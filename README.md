SynaptiQ AI Website

This repository contains the static website for SynaptiQ AI.

Structure:
- index.html — homepage with the original design preserved
- css/style.css — extracted styles for the site
- js/script.js — interactive navigation and homepage behavior
- images/ — image assets folder (empty placeholder)
- pages/ — placeholder page templates for About, Features, Privacy, Terms, Contact, and FAQ
- downloads/synaptiq-ai.apk — APK download file placeholder

Usage:
- Open `index.html` directly in your browser for local preview.
- All pages are mobile-friendly and use the same header/footer.
- The download button on the homepage links to `downloads/synaptiq-ai.apk`.

Notes:
- The homepage design, colors, fonts, and animations are preserved exactly as provided.
- Placeholder pages contain minimal text and shared site navigation.
